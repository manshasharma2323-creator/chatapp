AI Chat Hub

An AI-powered, real-time
chat platform

AI Chat Hub is a distributed real-time messaging application that pairs instant, persistent conversations with a built-in AI layer — smart reply suggestions grounded in your chat history, and a standalone AI assistant — on top of a secure, JWT-authenticated backend.

Core features

Real-time messaging
Messages are delivered instantly over a persistent WebSocket (STOMP over SockJS) connection — no polling.
AI smart replies
Get short, contextual reply suggestions generated by your configured AI provider, grounded in the real conversation.
Conversation memory
The AI assistant and smart-reply engine read recent message history, so responses stay on-topic across turns.
Online / offline presence
Live presence broadcasts show who's currently connected, down to the individual conversation.
Secure authentication
Stateless JWT bearer tokens and bcrypt-hashed passwords protect every account and API route.
Persistent chat history
Every message is stored in MySQL, so conversations, unread counts, and history survive a reload or a new device.

How it fits together

The frontend is a static client that talks to a decoupled Spring Boot backend over a CORS-enabled REST API for auth, contacts and history, and a STOMP/WebSocket channel for live messages, typing indicators and presence. AI features call the same backend, which routes the request to whichever provider — OpenAI or a local Ollama model — is configured, so the rest of the app never needs to know which one is active.
