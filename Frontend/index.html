Everything a real-time chat app should be

Built on a secure Spring Boot backend with live WebSocket delivery and a real AI layer — not a mockup.

Real-time messaging
Messages arrive instantly over a persistent WebSocket connection — no polling, no delay.
AI smart replies
Short, contextual reply suggestions generated by your configured AI provider, grounded in the real conversation.
Conversation memory
The AI assistant reads recent history, so its answers stay on-topic across turns.
Online / offline presence
Live presence broadcasts show who's online right now, down to the individual conversation.
Secure authentication
Stateless JWT bearer tokens and bcrypt-hashed passwords protect every account and API route.
Persistent chat history
Every message is stored in MySQL, so conversations survive a reload or a new device.

An AI-powered, real-time chat platform

AI Chat Hub pairs instant, persistent conversations with a built-in AI layer — smart reply suggestions grounded in your chat history, and a standalone AI assistant — on top of a secure, JWT-authenticated Spring Boot backend with a MySQL-backed message store.
